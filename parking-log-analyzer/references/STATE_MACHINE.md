# 泊车状态机参考

## 泊入状态机 (ParkIn)

| 步骤值 | 名称 | 图标 | 说明 |
|--------|------|------|------|
| 0 | None | 🔘 | 初始/空闲 |
| 1 | 等待APP启动泊入 | ⏳ | 等待用户触发 |
| 2 | APP启动泊入 | ▶️ | 用户已启动 |
| 10 | 自检中 | 🔧 | 车辆条件检查 |
| 11 | 自检通过 | ✅ | 条件满足 |
| 20 | 泊入进行中 | 🚗 | 正在执行泊入 |
| 50 | 泊车结束中 | 🛑 | 泊入完成，收尾 |
| 51 | 车辆已下电 | 🔌 | 车辆下电 |
| 52 | 泊车结束 | 🏁 | 成功完成 |
| 60 | 取消泊入 | ❌ | 被取消（可恢复） |
| 61 | 泊车已取消 | 🚫 | 取消确认 |

### 正常泊入流程

```
0(None) → 1(等待APP) → 2(APP启动) → 10(自检中) → 11(自检通过) → 20(泊入进行中) → 50(结束中) → 52(结束)
```

### 异常路径

```
自检中(10) → 条件不满足 → 60(取消泊入) → 61(泊车已取消)
泊入进行中(20) → PAA_Quit_Indication≠0 → 50(结束中) → 51(车辆已下电)
```


## 状态机异常判断

| 异常现象 | 特征日志 | 可能原因 |
|----------|----------|----------|
| 卡在自检中 | step 10/110/204 后无进展 | 车辆条件不满足 |
| 突然跳转结束 | 缺少中间步骤 | PAA_Quit_Indication 触发 |
| 握手失败 | 卡在 step 104 | BLE 连接不稳定 |
| 状态机重置 | 同一会话内多次相同 step | 收到了重复报文或挑战响应超时 |
